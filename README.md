# Competitive Programming

Solutions are organized by the main algorithmic idea used by the implementation.
Platform links and problem metadata remain in each source file.

## Problem library

- [Graph](problems/graph/): bipartite checking, connectivity, cycles, shortest paths, and grid BFS
- [Strings](problems/strings/): substring counting, reconstruction, binary strings, and palindrome logic
- [Dynamic programming](problems/dp/): sequence, binary-search, and optimization states
- [Greedy](problems/greedy/): selection, sweep lines, prefix scans, array transformations, and matrix operations
- [Math](problems/math/): arithmetic, geometry, formulas, modular arithmetic, and number theory
- [Sorting](problems/sorting/): ordering and group-based solutions
- [Data structures](problems/data_structures/): sets and binary search
- [Bit manipulation](problems/bit_manipulation/): XOR and bitwise construction
- [Constructive](problems/constructive/): direct sequence and array construction
- [Combinatorics](problems/combinatorics/): counting and permutation/range constructions
- [Implementation](problems/implementation/): simulation, counting, and small direct solutions
- [Games](problems/games/): game strategies and game-specific number theory
- [Queries](problems/queries/): query processing and dynamic sets
- [Brute force](problems/brute_force/): bounded search and operation enumeration

## Review areas

- [Review queue](problems/review/): incomplete, unsafe, or insufficiently validated solutions
- [Legacy duplicates](problems/archives/legacy_duplicates/): duplicate implementations retained for comparison

The source-platform folders are no longer the primary navigation path. The complete source-to-destination record is in [docs/file-movement-plan.md](docs/file-movement-plan.md).
